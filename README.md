# 研墨

> 一个**会问你问题**的码字软件。AI 只问，不写。

Windows 桌面写作工具，面向中文网文作者。核心承诺：**不丢稿、百万字不卡、CJK 算得对、能一键交稿**。

## 三条主线

1. **地基**：本地优先、永不丢稿（快照 + 崩溃恢复 + 可自测的恢复演练）、百万字流畅、中文字数与排版做对（全行业空白：Scrivener 对同一份 8596 字中文在 macOS 报 6108、Windows 报 1030）
2. **叩问**（头号差异化）：从故事进展、大纲、未回收伏笔、灵感碎片等多要素出发，**实时问答引导作者想清楚要写什么**。机制产问题、LLM 只润色；支持延后 / 舍弃 / 静音 / **记灵感**；题目可键盘或口述作答
3. **创作留痕**：口述轨迹 + 版本演进 + 问答记录，一键打包成真人创作的自证材料

**明确不做**：AI 自动生成正文（起点 / 番茄 / 晋江全线封杀）。我们的能力全部落在平台白名单内——文字校对、创意要素辅助、创意粗纲辅助。

## 架构

```
crates/yanmo-core/   引擎：数据权威 + 全部业务逻辑（零 UI 依赖）  ← AGPL 核心
crates/yanmo-proto/  协议定义（P0 只设计不实现）
crates/yanmo-cli/    命令行入口：只读 + 导出（界面起不来时的取稿路径）
app/                 官方桌面壳（Tauri 2 + Vue 3 + TipTap 3）
```

**进程边界 = 许可边界**：核心是「可执行程序 + 公开协议」，不是"别人必须链接的库"。因此第三方可以用任何语言（包括让 AI 搓）写前端壳而**不受 AGPL 约束**；想链接核心的则必须整体开源。详细边界见 CONTRIBUTING.md 的生态许可说明。

**数据流向（单一真相源）**：数据目录与数据库文件由桌面壳（Rust 侧）解析并打开，稿件读写全部发生在核心；
界面**没有文件系统权限，也不拼接任何路径**，它只能通过命令取数据。好处很直接：写入者只有一个，
不会出现两套数据互相覆盖；换主题、换界面甚至换一套壳，都不会碰到数据层。

**写入节奏**：击键与撤销留在编辑器内部，**停笔约 250 毫秒**才落盘一次；每 2–5 秒核一次
"库里的正文还是不是我手上这份"（只比内容指纹）。核不上或长时间存不下去时，
**先把手上这份留成快照，再把库改回这一版**——不赌运气。

**关窗也不赌运气**：关闭窗口会先落盘，**存不下去就拦住**（重试保存 / 导出到文件 / 仍然退出）；正常退出前留一份版本快照。若上次是被强制结束的，下次启动会明确告诉你，并回到崩溃前那一章的最后落盘版本。

**界面起不来也有路把稿子拿出来**：随发行包附带一个命令行程序，**双击打开就是中文菜单**（读取稿子 / 检查数据库健康度 / 导出某一本或某一篇 / 导出全部），不用记任何参数——它是显卡崩溃、图形界面崩溃、驱动失活这类**极限情况**下的备用导出工具。它只读与导出，**没有任何能修改稿库的命令**；它有哪些能力、发行版为什么改不了稿、你怎么自己验证，都写在 [SECURITY.md](./SECURITY.md)。

这条边界不是口头约定：仓库里有一条随测试一起跑的机械检查——核心不得依赖任何界面框架、
界面不得出现文件读写或取路径的接口、界面只能经单一通道与核心对话、权限集逐项最小化且不含路径能力。

## 开发

需要 Windows 侧工具链（Rust 1.97+、Node 24+、Visual Studio Build Tools、WebView2）与 `tauri-cli`。

```bash
# 前端依赖
cd app/frontend && npm install

# 开发运行（在 app/ 目录下）
cargo tauri dev

# 构建
cargo tauri build
```

## 支持研墨

如果研墨帮到了你，可以请我喝杯茶：**[爱发电](https://afdian.com/a/siukee)**。

**但别有负担，也别抱着"买了未来"的期待**——捐赠没有回报，我也**不承诺会一直更新**。我把话说明白：

- 我真正承诺的只有一件事：**不让你被困住**。源码公开、数据能一键导出、格式开放——**哪怕我明天就不更新了，你也不会因此丢掉稿子，或换不了工具**。
- 这比"我会一直更新"实在。这个品类已经有太多产品悄悄消失（灯果停服、墨鸣停运、墨咕服务不可用），而作者最怕的从来不是软件变旧，是**稿子被锁在里面、无路可走**。
- 所以捐赠是"请我喝杯茶"，不是"购买未来"。**你的稿子始终属于你——这件事不需要付费。**

## 许可

**AGPL-3.0-or-later**。简单说：

| 你想做的 | 可以吗 | 义务 |
|---|---|---|
| 自己用、随便改 | ✅ | 无 |
| 做主题 / 皮肤 / 字体 / 词库包并分享 | ✅ | 无 |
| 写独立前端壳（Android/mac/Linux）调我们的协议 | ✅ | **无**（可闭源，甚至可收费） |
| fork 核心代码做自己的版本并分发 | ✅ | **整个版本必须 AGPL 开源** |
| fork 核心 + 改名闭源卖 | ❌ | 侵权 |

详见 [CONTRIBUTING.md](./CONTRIBUTING.md) 的生态许可说明。
