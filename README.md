# 研墨

> 一个**会问你问题**的码字软件。AI 只问，不写。

Windows 桌面写作工具，面向中文网文作者。核心承诺：**不丢稿、百万字不卡、CJK 算得对、能一键交稿**。

## 先看这里：现在的状态

**研墨还在开发中**，请按下面这句来理解它现在的可用程度：

- ✅ **已经能用的（地基）**：编辑器、目录树、书架、回收站、每章版本快照、排版清理、
  投稿包编译（docx / 分章 txt / 合并 txt）、导出、备份与从备份恢复、每日码字目标与日历、
  专注模式、命令行只读取稿。日常写长篇，这些够用。
- 🚧 **还在开发的**：「叩问」（会问问题的那个能力）与「创作留痕」两条线**尚未发布**——
  README 后面会写它们是什么，但**现在还没有**，别按它们来安排你的预期。
- ⚠️ **一句老实话**：这是个还在长的软件。想试写没问题，但**正式稿件请同时留一份在别处**
  （研墨自己有快照、回收站、备份与导出，但"另存一份"是最省心的保险）。

关于"它到底保证什么、做不到什么"，见 [SECURITY.md](./SECURITY.md)——我们把做不到的也写在明处。

## 用起来（使用者路径）

### 1. 下载哪个

发布页里通常有两个东西，挑一个就行：

| 文件 | 适合谁 | 装完在哪 |
| --- | --- | --- |
| `研墨-<版本>-setup.exe` | 大多数人 | 开始菜单 + 桌面快捷方式，随时能在「应用和功能」里卸载 |
| `研墨-<版本>.exe` | 不想安装的人（便携版） | 双击即用，程序自己不写安装信息 |

同时会有一个同名的 `.sha256` 文件——那是校验和，见下面「没签名，怎么确认拿到的是原件」。

### 2. 怎么装

双击 `setup.exe`，跟着向导走就行：

- **按当前用户安装**（不需要管理员权限，也不会弹 UAC）；
- 安装向导有简体中文与英文；
- 写入系统的东西只有：**标准的卸载信息**（「应用和功能」里那条记录）、开始菜单项，
  以及你勾选的桌面快捷方式——**不加开机自启，不做其它注册表写入**；
- 最后一页有一个「运行研墨」的勾选框（默认勾上）：不想现在就启动，取消它即可。

### 3. 首次启动会发生什么

1. **先问你一句"稿子放哪"**：给你一个推荐位置（一般是你的「文档」或主目录下新建的文件夹），
   你也可以当场换成别的盘。**它只会在你确认的位置建目录**，不会到处写文件。
   以后想换位置：设置里随时可换，**换的时候是复制过去，旧位置一个字都不删**。
2. **建你的第一本书**：一次问清书名、作品类型（长篇 / 短篇集 / 单篇）、简介、卷与章的命名写法
   （「第1章 / 第一章 / 第001章 / 不编号」随时可改，已有的名字不会被改）。
3. **开写**。稿子在哪随时能看见：**顶栏最右侧那行小字**就是数据目录，点一下用文件管理器打开。

### 没签名，怎么确认拿到的是原件（SmartScreen 提示怎么继续）

研墨的安装包**目前没有代码签名**（原因见下）。所以第一次运行 Windows 会拦你一下：

> **Windows 已保护你的电脑** —— 未知发布者

继续的方法：点提示框里的 **「更多信息」**，然后点 **「仍要运行」**。就这么两步。

**为什么暂时没签名**：代码签名证书要花钱，而且现在多是云签名或硬件令牌，流程还在评估；
我们打算等有真实下载量之后再决定买不买。在那之前，**"源码公开 + 可自己构建"是比签名更硬的凭据**。

想确认手上的文件没被掉包，两条路：

```bat
:: ① 对照发布页给的校验和（构建时会自动生成同名的 .sha256 文件）
certutil -hashfile 研墨-0.41.7-setup.exe SHA256

:: ② 最硬核的一条：自己从源码构建（见下面「开发」），出来的就是原件
tools\build-release.bat
```

介意"未知发布者"这个提示的话，还有一个折中：**先用便携版**（同样会提示），
或者先安装后立即用命令行入口确认一下稿子都在（见 SECURITY.md 的「命令行入口」）。

### 常见坑

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 双击 exe 一片白屏 | 那是**开发模式**的产物：它启动后去连本地开发服务器 | 用发布页的产物；要自己构建就别用 `cargo build --release`，走 `tools\build-release.bat` |
| 杀毒软件报警 / 拦截 | 未签名的自研程序常见误报 | 加白名单，或用上面两条路先核对原件；报毒信息欢迎反馈 |
| 找不到稿子在哪 | 数据目录由程序决定，不在程序安装目录里 | 看顶栏最右侧那行小字（可点开），或设置面板的「关于」 |
| 想手动备份 | 想自己复制一份到 U 盘 | 直接复制**整个数据目录**（含 `.db` 文件）即可；程序内的备份功能更省事，且会写回体检 |
| 重装系统 / 换电脑 | 稿子默认在用户目录下 | 先把数据目录换成你管理的盘位，或先做一次备份（见 SECURITY.md 的「数据在哪、怎么带走」） |
| 卸载后稿子还在吗 | 卸载只删程序 | **稿子不被删**（数据在独立目录里）；确认不要了再自己去删那个目录 |

## 研墨想做的三件事（一条已能用，两条开发中）

1. **地基**（✅ 已能用）：本地优先、永不丢稿（快照 + 崩溃恢复 + 可自测的恢复演练）、百万字流畅、
   中文字数与排版做对（全行业空白：Scrivener 对同一份 8596 字中文在 macOS 报 6108、Windows 报 1030）
2. **叩问**（🚧 开发中，头号差异化）：从故事进展、大纲、未回收伏笔、灵感碎片等多要素出发，
   **实时问答引导作者想清楚要写什么**。机制产问题、LLM 只润色；支持延后 / 舍弃 / 静音 / **记灵感**；
   题目可键盘或口述作答
3. **创作留痕**（🚧 开发中）：口述轨迹 + 版本演进 + 问答记录，一键打包成真人创作的自证材料

**明确不做**：AI 自动生成正文（起点 / 番茄 / 晋江全线封杀）。我们的能力全部落在平台白名单内——文字校对、创意要素辅助、创意粗纲辅助。

## 它是怎么攒起来的（技术说明）

```
crates/yanmo-core/   引擎：数据权威 + 全部业务逻辑（零 UI 依赖）  ← AGPL 核心
crates/yanmo-proto/  协议定义（只设计不实现）
crates/yanmo-cli/    命令行入口：只读 + 导出（界面起不来时的取稿路径）
app/                 官方桌面壳（Tauri 2 + Vue 3 + TipTap 3）
```

**进程边界 = 许可边界**：核心是「可执行程序 + 公开协议」，不是"别人必须链接的库"。因此第三方可以用任何语言（包括让 AI 搓）写前端壳而**不受 AGPL 约束**；想链接核心的则必须整体开源。详细边界见 CONTRIBUTING.md 的生态许可说明。

**数据流向（单一真相源）**：数据目录与数据库文件由桌面壳（Rust 侧）解析并打开，稿件读写全部发生在核心；
界面**没有文件系统权限，也不拼接任何路径**，它只能通过命令取数据。好处很直接：写入者只有一个，
不会出现两套数据互相覆盖；换主题、换界面甚至换一套壳，都不会碰到数据层。

**写入节奏**：击键与撤销留在编辑器内部，**停笔约 250 毫秒**才落盘一次；每 2–5 秒核一次
"库里的正文还是不是我手上这份"（只比内容指纹）。核不上或长时间存不下去时，
**先把手上这份留成快照，再把库改回这一版**——不赌运气。

**关窗也不赌运气**：关闭窗口会先落盘，**存不下去就拦住**（重试保存 / 导出到文件 / 仍然退出）；正常退出前留一份版本快照。若上次是被强制结束的，下次启动会明确告诉你，并回到崩溃前那一章的最后落盘版本。

**界面起不来也有路把稿子拿出来**：随发行包附带一个命令行程序，**双击打开就是中文菜单**（读取稿子 / 检查数据库健康度 / 导出某一本或某一篇 / 导出全部），不用记任何参数——它是显卡崩溃、图形界面崩溃、驱动失活这类**极限情况**下的备用导出工具。它只读与导出，**没有任何能修改稿库的命令**；它有哪些能力、发行版为什么改不了稿、你怎么自己验证，都写在 [SECURITY.md](./SECURITY.md)。

**零出网**：研墨不发起任何网络连接，核心与命令行入口都不依赖网络库。这条有随测试跑的机械检查盯着，
SECURITY.md 里给了三步自验方法（看依赖树 / 跑守卫 / 断网实测）。

## 开发

### 前置条件（逐项）

| 需要 | 版本 / 说明 |
| --- | --- |
| Rust | 1.97 或更新（`rustup` 装 stable 即可） |
| Node.js | 24 或更新（含 npm） |
| **Visual Studio Build Tools** | 勾选「**使用 C++ 的桌面开发**」工作负载；其中必须有 **MSVC v143 生成工具** 与 **Windows 10/11 SDK**（缺了会在编译 C 依赖时报 `link.exe not found`） |
| WebView2 Runtime | Windows 10/11 一般自带；没有就装 Microsoft 的 Evergreen Runtime |
| `tauri-cli` | `cargo install tauri-cli --version '^2'`（或 `npm i -g @tauri-apps/cli`） |

### 跑起来

```bat
cd app\frontend
npm install

cd ..
cargo tauri dev
```

### 跑测试

```bat
:: 核心与桌面壳（含边界机械检查：界面不碰文件系统、权限集最小化、零出网等）
cargo test --workspace

:: 前端（纯 node 测试，不需要浏览器）
cd app\frontend
npm test
```

### 出一条能发给别人的安装包

```bat
tools\build-release.bat
```

一条命令走完：工具链自检 → 版本一致 → 前端构建 → **跑测试（失败就不出包）** → 打包 →
产物归集到 `dist\`（文件名带版本号，附 SHA256）。产物是 NSIS 安装器，双击即可安装。

> ⚠️ **别用 `cargo build --release` 当发布产物**：单独这么构建出来的是**开发模式**的可执行文件——
> 它启动后会去连 `http://localhost:1420`（开发服务器），双击就是一片白屏。要出能直接双击的产物，
> 必须走 Tauri 自己的构建路径（`cargo tauri build`，也就是上面那条命令做的事）。

其它参数：`--no-bundle`（只出可执行文件）、`--skip-tests`（本地反复出包时用；正式出包别用）、
`--out <目录>`（换归集位置）。
