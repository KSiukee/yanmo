# 研墨

## 一句话

**研墨是一个装在你自己电脑上的中文写作软件**——给写小说的人用的，稿子只在你的机器里，
不联网、不上传、不需要注册账号。

- **它帮你做什么**：安安静静写长篇。目录、版本历史、备份、投稿包导出、码字统计，
  以及一个"停笔就自动存、存不下去会拦住你"的安心感。
- **它不做什么**：不替你写正文（AI 只问、不写）；不把你的稿子传上云；不搞会员锁功能。
- **它怎么保护你的稿子**：稿子就是你自己电脑上的一个普通文件夹（随时能复制、能带走）；
  每章都有版本历史，删掉的东西进回收站，备份写到你自己指定的地方——**哪怕这软件明天不更新了，
  你的稿子也不会被锁在里面**。
- **未来会有什么**：会"问你问题"的写作辅助、创作过程留痕（口述与修改轨迹）、
  以及第三方可以自己写模块的生态（见下面「还在做和计划做的」）。

> **现在的状态：开发中。** 写长篇的日常功能已经能用，但请**正式稿件同时留一份在别处**。
> 细节在下面「当前已经能用」那一节。

## 它是什么（人话版）

一个 Windows 桌面软件。你打开它，就像打开一个带目录树的稿纸本：左边是书的目录，
中间是正文，顶部告诉你"稿子放在哪"。它会把你的每一章存进一个数据库文件，
同时留着每一章的旧版本；稿子存在**你自己选的一个文件夹**里，不在软件安装目录里，也不在网上。

它不是"云端写作平台"，没有服务器替你保存。好处是没人能看你写的东西、服务停了你的稿子也在；
代价是**它不能替你在多台设备之间自动同步**——换电脑要自己拷（软件里有"备份"和"从备份恢复"帮你做这件事）。

## 能帮你什么

| 你遇到的 | 研墨怎么做 |
| --- | --- |
| 写几十万字，章节多、翻不动 | 目录树 + 卷/章结构 + 跳转；一卷写到尾声时会问你一句「要不要在这里收卷」（**只提议，不动结构**）；不同书的稿子放在一个"书架"里 |
| 手滑删了一章、改错了想找回 | 每章有**版本历史**；删掉的东西进**回收站**，能整章、整本捞回来 |
| 怕丢稿 | 停笔约 0.25 秒自动保存；**存不下去会拦住你**并让你把手上的内容导出来；可以设**多处备份**，每天自动做一次 |
| 不确定字数和进度 | 逐字、不含标点、按词三种字数口径；今日进度、每日目标、码字日历 |
| 要交稿给编辑 | 一键导出：投稿版 `.docx`、分章 `.txt`、合并 `.txt` |
| 写着写着分心 | 专注模式（`F9`）：只留正文和一条细状态栏 |
| 界面万一打不开 | 附带一个命令行程序，**双击就是中文菜单**，能读出稿子、导出稿子 |
| 不想被软件绑住 | 源码公开、格式开放、稿子能一键导出离开——见「许可」一节 |

## 不做什么

- **不自动生成正文**。平台（起点/番茄/晋江）对 AI 生成正文是全线封杀的，我们也不做；
  研墨的能力落在平台白名单内：文字校对、创意要素辅助、创意粗纲辅助。
- **不把稿子传上云**，软件本身不联网（这点有机器检查盯着，见「它凭什么可靠」）。
- **不做付费墙**：核心功能全部开源、永久免费；将来若有增值模块，也是独立程序，
  不锁核心能力。
- **不偷偷改你的稿子**：所有"自动"的动作（备份、排版建议）都是**只报告不自动改**，
  要不要动由你点头。

## 怎么保护你的宝贵数据

五件事，从"随手"到"最坏情况"：

1. **稿子在哪，一眼可见**：软件顶栏最右边那行小字就是数据文件夹，**点一下就用资源管理器打开**；
   设置面板的「关于」里也有。它就是一个普通文件夹，你可以随时复制、压缩、拷到 U 盘。
2. **写的时候不用管**：停笔自动保存；每一章都自动留旧版本；每 2–5 秒核对一次
   "库里的正文还是不是我手上这份"，对不上会先把你手上这份留成快照再回写——不赌运气。
3. **关窗/崩溃也不赌**：关窗先落盘，存不下去会拦住你；被强杀或断电后重启，
   它会告诉你"上次不是正常退出"，并回到最后一版。
4. **备份 + 能带走**：把备份写到你指定的几处（U 盘、移动硬盘都行），每天首次启动自动做一次，
   写完还会读回来体检；换电脑时用「从备份恢复」，它会**先告诉你会丢几天、多少字**，并把原库留底。
   另外随时能把整本书导成 `.docx` 或 `.txt` 带走。
5. **最坏情况也留了一手**：每份备份里还放着一份**不依赖数据库**的成稿（分章 txt + 一份 JSON）。
   万一数据库文件彻底坏了打不开，可以把那份成稿**导进一个新库**，目录与正文整本收回来
   （命令行 `import`，**默认只看不写**，确认无误再加 `--yes`；只新建，不动你原有的书）。
   代价写在明处：**导入的行没有原来的写作时间**，版本历史与"每章一句话"回不来。

**我们做不到的也写在明处**（备份包不加密、单库仍是单点、强杀进程会丢最后几秒……）：
完整清单和"遇到问题怎么办"见 [SECURITY.md](./SECURITY.md)。

## 当前已经能用

- 编辑器：正文、章节标题、"这一章的一句话"、自动保存、字数三口径
- 目录树：卷/章结构、拖动排序、改名、插入、每章字数
- 分卷：一卷写到差不多时会**问你一句**「要不要在这里收卷」——只提议、不动结构，
  收好了能一键撤销（撤了正文一个字不动）；阈值跟**你自己的收卷节奏**走（写得多了就按你的中位数算）
- 编号：章的号跟着位置自动排（插章、删章、拖动、捞回都不用管）；
  **可以跨卷延续**（第2卷接着第11章，默认），也可以每卷从第1章重来——设置里选，改一下立刻全见效
- 多作品：书架、新建（一次问清书名/类型/简介/命名写法/一卷大概多少章）、作品语言（中文/英文/日文）
- 找回：回收站（整本或整段捞回）、每章版本历史（对照、回滚）
- 安全：多处备份、从备份恢复、关窗兜底、崩溃提示、单实例锁
- 交稿：投稿版 docx、分章 txt、合并 txt；排版清理（只报告，你勾了才动）
- 统计：今日进度、每日目标、码字日历、连续天数
- 舒适：专注模式（`F9`）、大纲悬浮卡片、常用快捷键（`Ctrl+S` 立刻保存、`Ctrl+Alt+←/→` 换章等）
- 排版：设置 → 排版里调**字号 / 行距 / 字距**（只改你看正文的观感：不进导出、不动正文一个字，
  改完立刻生效、重启还在；面板里有一段示例字，调的时候就看得到效果）
- 取稿：命令行工具（界面打不开时的备用出口；只读与导出之外，还有一条**不依赖数据库**的
  「从成稿导入」——默认只看不写，确认后加 `--yes` 才把整本书收回新库）

## 它凭什么可靠（不用懂代码也能看懂的几条）

1. **每次出包都先跑一遍自动检查，过不了就不出包**：截至目前有 **500 多项**自动检查
   （核心 300 多项 + 界面 200 多项，随版本只增不减），涵盖"写、存、关、重开、恢复、导出"这些日常路径。
   出包的脚本是"检查失败就停"，不会"报个警告照样发"。
2. **有专治"最坏情况"的检查**：故意模拟"升级到一半断电""库里的正文和手上的对不上"
   "只读一遍之后稿子有没有被偷偷改动"——这类检查不过，包也出不来。
3. **有专治"偷偷联网"的检查**：机器会扫描全部代码，出现任何联网能力就报警。
   你也可以自己验证：断网后正常写作、备份、导出，应当毫无异常；
   或用系统防火墙看 `yanmo.exe` 的连接列表——**应当始终为空**。
4. **手滑有退路**：删了的在回收站、改错的在版本历史、丢了的有备份，
   连**数据库本身坏掉**都还有一条"从成稿导入"——四条路互相独立，任一环节出问题都不会让你失去稿子。
5. **中文字数算的是"中文规矩"**：逐字含标点/不含标点/按词三种口径都给你，
   不拿英文的分词规则糊弄中文（同类软件对同一份 8596 字中文，有报 6108 也有报 1030 的）。
6. **可以不信任我**：源码公开，一条命令就能自己构建出安装包（见下）。
   每个发布文件旁边都附 `.sha256` 校验和，你可以核对拿到的是不是原件。

## 版本与下载

- **当前版本**：0.67.0
- **下载**：GitHub Releases —— <https://github.com/KSiukee/yanmo/releases>
  （装哪个、怎么装、第一次打开会看到什么，见下面的「上手三步」）
- **校验和**：每个安装包与便携版旁边都有一个同名 `.sha256` 文件，可用来核对文件有没有被改过：

  ```bat
  certutil -hashfile <你下载的那个文件名> SHA256
  ```

- **一键构建**（想自己从源码出包）：装了 Rust / Node / Visual Studio Build Tools 之后，
  在仓库根目录跑：

  ```bat
  tools\build-release.bat
  ```

  它做六件事：工具链自检 → 版本一致 → 前端依赖与构建 → 跑测试（失败就不出包）→ 打包 →
  把产物、校验和与构建指纹放进 `dist\`。
  前置条件、开发环境、跑测试的命令，都写在 [CONTRIBUTING.md](./CONTRIBUTING.md) 的「开发须知」。
- **这些文件是怎么来的**：每次出包都会同时生成一份 **`yanmo-<版本>-build-fingerprint.txt`**——写着这一包
  是哪次源码提交、用哪套工具链构建的，以及产物的 SHA256。发版的完整流程（含"发出去发现严重问题
  怎么办"）见 [RELEASING.md](./RELEASING.md)。
- **模块开发工具**：等模块生态（模块市场）实装之后再一并放出，现在还没有。

### 没签名，第一次运行会被 Windows 拦一下

研墨的安装包**目前没有代码签名**，所以第一次运行会弹：

> **Windows 已保护你的电脑** —— 未知发布者

继续的方法：点 **「更多信息」** → 点 **「仍要运行」**。两步就好。

**为什么暂时不签**：证书要花钱，而且现在多是云签名或硬件令牌，流程还在评估；
打算等有真实下载量之后再决定。在那之前，"源码公开 + 可以自己构建 + 附校验和"
是比签名更硬的凭据。介意这个提示的话，也可以先用便携版，或者干脆自己构建一个。

## 上手三步

1. **下载哪个**（三个文件是一份源码、一次构建出来的，只是形态不同）：
   - `yanmo-<版本>-setup.exe` —— **安装版**：开始菜单里能找到，随时可卸载。**多数人选这个**。
   - `yanmo-<版本>-portable.exe` —— **便携版**：双击即用、不写注册表；稿子仍放在系统里的数据位置。
   - `yanmo-<版本>-portable.zip` —— **绿色版**（解压即用）：稿子放在**解压出来的那个文件夹**里，
     跟着文件夹走（拷到 U 盘、拷到别的机器，稿子一起走）。适合"整个装在一个文件夹里带走"。
2. **怎么装**：安装版双击跟向导走（按当前用户安装，不需要管理员权限，**不加开机自启**）；
   便携版双击即用；绿色版解压到你想放的地方，双击里面的「研墨.exe」。
3. **第一次打开**：它会先问你一句"稿子放哪"（给一个推荐位置，也可以换成别的盘）。
   进去以后正文上方有一条提示，给两个入口：**「建一本书」**（一次问清书名、类型、简介、卷章命名、
   一卷大概多少章），或者**「就在这一本里写」**（自动建的那本空白书还没名字，起个名就能开写）。
   之后就只剩写作本身了。

### 更新与搬家（绿色版最要紧的一条）

| 你想做的 | 怎么做 |
| --- | --- |
| **升级**（三种形态都一样） | 下载新版，覆盖旧的程序文件即可。**稿子不用动**：数据在你原来的数据位置，第一次打开会自动把库升到新结构（不需要单独的迁移工具）。升级前建议先备份一次。 |
| **绿色版升级** | 把新版 zip **解压到同一个文件夹**（也就是覆盖里面的「研墨.exe」），**千万别动 `data\`**。**别解压到一个新文件夹**——那里的 `data\` 是空的，看起来会像"稿子没了"（稿子没丢，在旧文件夹里）。 |
| **绿色版搬走 / 换电脑** | 把**整个文件夹**拷过去。 |
| **回退到旧版** | 可以：旧版读得回新版写的库，正文一字不差；但如果库已经被新版**升过结构**，旧版会**明确拒绝**打开（提示升级），不会猜着读、也不会动你的库。 |
| 卸载以后稿子还在吗 | **在**。卸载只删程序，稿子在独立的数据文件夹里，要删得你自己去删。 |

⚠️ 绿色版依赖系统自带的 **WebView2**：Win11 一定有；Win10 1803 以后多半也自带。
老机器 / 精简系统上如果打开是白屏，请改用安装版。

### 常见问题

| 现象 | 怎么办 |
| --- | --- |
| 目录里冒出来一句「要在这里收卷吗」 | 你写的那一卷到尾声了（阈值按**你自己的收卷节奏**算）。点「在这里收卷」才会动结构，点「再等等」这一次就不提了（连着两次这一卷不再提）；收好了目录栏里留一个**撤销**，撤销只动结构、正文一个字不动 |
| 第二卷的章号跟以前不一样了 | 默认是**跨卷延续**（第1卷 1~10，第2卷接着 11~20）。想改成每卷从第1章重来：**设置 → 命名 → 「章节编号」**；改一下立刻全见效，标题与正文一个字都不动 |
| 双击后一片白屏 | 那是**开发模式**的产物（会去连开发服务器）。请用 Releases 里的文件；自己构建请走 `tools\build-release.bat` |
| 杀毒软件报警 | 未签名的自研程序常见误报。加白名单，或用上面的 `.sha256` 核对原件；也欢迎来 issue 反馈 |
| 找不到稿子在哪 | 看顶栏最右边那行小字（可点开），或设置面板的「稿子放在哪」；「关于」里也能一键打开那个文件夹 |
| 想手动备份 | 直接把**整个数据文件夹**复制到 U 盘即可；软件内的备份功能更省事，还会读回体检。**绿色版别只备份在自己文件夹里**——U 盘丢了就一起丢 |
| 重装系统 / 换电脑 | 先做一次备份（或先把数据文件夹换到你管理的盘位），新机器上用「从备份恢复」 |
| 卸载以后稿子还在吗 | **在**。卸载只删程序，稿子在独立的数据文件夹里，要删得你自己去删 |
| 数据库文件坏了打不开 | 先试「从备份恢复」（换库前原库会留底）；连备份里的库也坏、只剩成稿时，让研墨开一个新库，用命令行 `import --from <备份包目录>` 把整本书导回来——它**默认只看不写**，先给数再动手 |

  而作者最怕的从来不是软件变旧，是**稿子被锁在里面、无路可走**。
- 所以捐赠是"请我喝杯茶"，不是"购买未来"。**你的稿子始终属于你——这件事不需要付费。**
